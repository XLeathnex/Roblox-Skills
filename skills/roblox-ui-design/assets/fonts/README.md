# Preview fonts

These open-licensed fonts let the preview renderer draw text in (or close to) the families Roblox ships.
They are used only by `scripts/rbxui` to render review images; Roblox Studio always uses its own fonts.

Source: https://github.com/google/fonts. Each font's licence is in `licenses/` (SIL Open Font License 1.1,
or Apache License 2.0 for Luckiest Guy, Special Elite and Permanent Marker).
